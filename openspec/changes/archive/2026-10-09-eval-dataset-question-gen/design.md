## Context

测评集生成已经会按文档拉原文，再调用 RAGAS `generate_with_langchain_docs`。现在不传 `query_distribution`，简单题和两种多跳平分题数，而且交进去的页全部做预处理。模糊、对抗、综合题没有。出题方案见 `docs/rag/测试集出题架构方案.md`。发布、打分、测评任务不在本变更里改。

## Goals / Non-Goals

**Goals:**

- 圈资料在本地完成，页数或节数封顶后再出题。
- 简单题、多跳只走 RAGAS，并按材料批次传入合成器。
- 模糊、对抗、综合题用同一批材料自己写，对抗题标准答案固定为「不知道」。
- 题数按 4:2:2:1:1 分配，余数给简单题。
- 上传文档由 content 按标题切节后返回，不写入分段表。

**Non-Goals:**

- MMR、LlamaIndex、DeepEval 出题。
- 改 `/internal/segments` 或把向量分段交给出题。
- 改 Ragas 打分、测评任务、发布门槛。
- 生成 Agent、分段 MCP 出题。

## Decisions

### D1. 新变更，不回头改 knowledge-publish-eval 的已完成任务

- **选择**：单独开 `eval-dataset-question-gen`。原变更里出题任务保持已完成记录，本变更替换出题实现。
- **理由**：原变更几乎做完，出题规格是另一套（Agent、20～40、1:2:1）。混回去会把已完成任务和现行规格拧在一起。
- **备选**：改原变更的 design 和任务。范围更大，发布和打分会被重新打开。

### D2. 先分爬取还是上传，再看大不大

- **选择**：任一原文文件带 `source_url` 视为爬取，按页圈。否则视为上传，调切节接口，按节圈。
- **小于等于 20**：这一批同时送给 RAGAS（三个合成器一次调用，能用的平分简单题+多跳的题数）和自写三类题。
- **大于 20**：简单题系统抽样 5 页或 5 节，单独一次 RAGAS，只放 `SingleHopSpecificQuerySynthesizer`。多跳另圈，单独一次 RAGAS，只放两种多跳合成器。自写三类题用多跳那一批，不用简单题那几页。
- **备选**：题数变大时简单题页数跟着涨。方案把简单题页数钉在 5，一页可以出多道题。

### D3. 多跳怎么配

- **爬取**：按页序隔段取起点，起点数等于多跳题数。只看这些起点页上的链接。超过一半起点都指向的地址当成导航丢掉。每个起点只留 1 条指向本文档页集合内的链接。没有合格链接就顺延到下一页，下一对起点仍按原间隔。去重后的页不超过 20，满了就停。
- **上传**：同一上级标题下、文档顺序里相邻的两节配成一对。再按多跳题数隔段取对，去重后不超过 20 节。没有上级标题的节不配。
- **建不出关系**：这次多跳调用得到 0 道，不把简单题合成器加回去。

### D4. 题数

- **选择**：权重 4:2:2:1:1，对应简单、多跳、综合、模糊、对抗。`question_count // 10` 为每份基数，余数全部加到简单题。50 道时是 20 / 10 / 10 / 5 / 5。
- **多跳对数**等于多跳题数，同时受 20 页（节）上限约束。

### D5. 切节只在 content，admin 不再切

- **选择**：`GET /internal/documents/{docId}/sections`。content 读这一份（或按文件顺序的多份）Markdown，按 ATX 标题切。代码围栏里的 `#` 不当标题。没有标题则大约每 8000 字切一节。返回顺序（从 0）、标题、上级标题、正文。不写分段表，不再按块大小切小。
- **理由**：向量分段还会二次切小，和出题的节不是同一件事。出题也不依赖已经做过 embedding。

### D6. 自写题一次结构化调用

- **选择**：用测评集已配置的对话模型，按综合、模糊、对抗的道数一次生成。对抗题落库前把标准答案写成「不知道」。提示词放 admin 的 `prompts.yaml`。
- **难度列**：RAGAS 题继续记 `synthesizer_name`；自写题记 `comprehensive` / `vague` / `adversarial`。

## Risks / Trade-offs

- [多跳材料建不出实体关系] → 这批记 0 道，测评集仍保留简单题和自写题；全部为空才标出题失败。
- [20 页正文仍可能很长] → 页数已经封顶；不再为省 token 做第二次模型筛选。
- [导航识别只看抽样起点] → 可能漏掉没出现在起点上的目录链接，也可能误伤真正常见页。只看这几页，避免把剩余页再扫一遍。
- [小于等于 20 时 RAGAS 平分简单题和多跳，对不齐 4:2] → 方案写明这一档一次调用、能用的平分。大于 20 才按题数分开调用。

## Migration Plan

1. 先上 content 切节接口，再改 admin 出题。旧的「整篇一次 RAGAS」在 admin 发版后不再走。
2. 已生成的测评集不重跑。新创建的测评集走新出题。
3. 回滚：admin 恢复整篇一次调用即可，切节接口留着不影响分段。

## Open Questions

- 无。页数上限、题数比例、合成器拆分都以出题架构方案为准。
