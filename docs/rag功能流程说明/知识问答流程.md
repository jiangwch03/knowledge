# 知识问答流程

基于已发布向量（正式版 `prod`）的会话式问答（`knowledge-retrieval`）。上游：资料上传 / 网页爬虫 → [切分与向量化](./切分与向量化流程.md) → 发布。

## 1. 收消息并启动 Agent

前端发问 → 落库用户消息 → 启动知识问答 Agent（SSE 流式）。

```mermaid
sequenceDiagram
    autonumber
    participant FE as 前端
    participant Agent as 知识问答 Agent

    FE->>Agent: 发送会话消息（SSE）
    Agent->>Agent: 落库用户消息，回执给前端
    Agent->>Agent: 启动本轮推理（见后续阶段）
    Agent-->>FE: 本轮结束
```

独立检索评测：`POST /retrieval/search`，只走混合检索，不经过 Agent。

### Agent 架构

```mermaid
flowchart TB
    FE["前端 SSE"] --> Svc["Agent 对话服务<br/>落库 · 流式协议"]
    Svc --> Graph["知识问答 Agent 图"]

    subgraph Agent["本轮中间件（按顺序）"]
        Graph --> RW["① 查询改写"]
        RW --> Gate["② 主题闸门"]
        Gate --> Ret["③ 混合检索<br/>仅知识库路径"]
        Ret --> Prompt["④ 提示组装"]
        Prompt --> Loop["⑤ 模型生成<br/>可选联网搜索"]
    end
```

每轮开始会清空上轮的改写结果、闸门结论和检索命中，避免短记忆串轮。

## 2. 查询改写与主题分流

```mermaid
sequenceDiagram
    autonumber
    participant Agent as 知识问答 Agent

    Agent->>Agent: 口语规范化 / 指代消解<br/>得到检索用查询
    Agent->>Agent: 主题闸门判定路径

    alt 知识库相关
        Agent->>Agent: 走知识库路径（下一步检索）
    else 闲聊 / 无关
        Agent->>Agent: 走客服路径（不检索知识库）
    end
```

## 3. 混合检索（仅知识库路径）

知识库路径才会检索；命中结果通过业务 SSE 推给前端，并注入后续提示。

```mermaid
sequenceDiagram
    autonumber
    participant Agent as 知识问答 Agent
    participant Ret as 检索服务
    participant Milvus as Milvus
    participant DB as 数据库
    participant FE as 前端

    Agent->>Ret: 混合检索（正式版向量 + 数据权限）
    Ret->>Milvus: 稠密向量 + 全文 BM25，RRF 融合
    Ret->>DB: 可选：父片正文回填
    Ret-->>Agent: 命中列表
    Agent-->>FE: 推送检索结果（查询词 + hits）
```

检索内部步骤：

```mermaid
flowchart TD
    Q["检索查询"] --> Emb["查询向量化"]
    Q --> Auth["鉴权 · 数据范围 · 正式版标签"]
    Emb --> Dense["向量召回"]
    Auth --> Dense
    Auth --> BM25["全文召回"]
    Dense --> RRF["融合排序"]
    BM25 --> RRF
    RRF --> Rerank{"可选精排"}
    Rerank --> TopK["截断 TopK"]
    TopK --> Expand{"是否回填父片"}
    Expand -->|是| Parent["用父片正文替换展示文本"]
    Expand -->|否| Hits["返回命中"]
    Parent --> Hits
```

检索异常时返回空命中，不伪造引用。

## 4. 生成回答

按分流结果切换系统提示；知识库路径会注入检索资料。模型流式输出；知识不足时可调用联网搜索。

```mermaid
sequenceDiagram
    autonumber
    participant Agent as 知识问答 Agent
    participant LLM as 对话模型
    participant Web as 联网搜索
    participant FE as 前端

    Agent->>Agent: 组装系统提示<br/>知识库路径则注入命中资料
    Agent->>LLM: 调用模型
    LLM-->>FE: 流式输出正文

    opt 知识库不足，需要外网补充
        Agent->>Web: 联网搜索
        Web-->>FE: 推送工具调用过程
        Agent->>LLM: 带上网页结果继续生成
        LLM-->>FE: 继续流式输出
    end
```

