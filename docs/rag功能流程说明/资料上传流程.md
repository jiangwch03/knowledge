# 资料上传流程

文档上传与 MinerU 解析入库（`knowledge-content`）。后续切分向量化见 [切分与向量化流程](./切分与向量化流程.md)。

> 表名以代码为准：上传任务表为 `knowledge_upload_document_parse_task`（下文图中简称上传记录/上传任务）；文件落在 `knowledge_document_file`，主表无 `status` 字段。

## 1. 流程全景

```mermaid
graph TD
    A["进入资料上传主页面"] --> B["展示文档列表"]
    B --> C["点击上传文件"]
    B --> D["点击Markdown转换"]

    C --> E["弹出上传表单弹框"]
    E --> F{"文件类型"}
    F -->|"MD"| G["文件上传至MinIO"]
    G --> H["创建上传任务<br/>预占版本号 status=PENDING"]
    H --> I["直接创建 knowledge_document<br/>+ document_file"]
    I --> I2["上传任务 status=CONVERTED"]

    F -->|"PDF/DOC/DOCX/XLSX"| J["文件上传至MinIO"]
    J --> K["创建上传任务<br/>预占版本号 status=PENDING"]
    K --> L["创建 knowledge_mineru_parse_task<br/>status=PENDING"]
    L --> M["发布 document.parse.pending"]
    M --> N["Stage2:申请链接并上传文件"]
    N --> O["Stage3:轮询解析结果"]
    O --> P["Stage4:合并ZIP生成Markdown"]
    P --> Q["创建 knowledge_document<br/>+ document_file"]
    Q --> Q2["上传任务 status=CONVERTED"]
    N -.->|"上传失败/超时"| R["Stage2 定时任务兜底重试"]
    R -->|"超过约24小时且<br/>batch全部失败"| S["解析任务 FAILED<br/>上传任务 USER_DECISION"]
    O -.->|"解析失败"| S
    P -.->|"md合并异常"| T["上传任务 CONVERT_FAILED<br/>Stage4 定时任务兜底"]
    T --> P
    S --> U{"用户决策"}
    U -->|"重试"| V["对失败分段新建任务<br/>上传任务/新任务 PENDING"]
    V --> N
    U -->|"删除"| W["软删除 上传任务/解析任务"]

    D --> X["进入Markdown转换"]
    X --> Y["上传TXT或粘贴文本"]
    Y --> Z["前端识别编码并转UTF-8"]
    Z --> AA["点击生成Markdown"]
    AA --> AB{"文件大小是否超限"}
    AB -->|"未超限"| AC["POST /document/txt/convert"]
    AB -->|"超限"| AD["提示文件过大"]
    AC --> AE["大模型生成Markdown"]
    AE --> AF["编辑Markdown"]
    AF --> AG["用户点击保存"]
    AG --> AH["保存Markdown到MinIO"]
    AH --> AI["创建上传任务 PENDING"]
    AI --> AJ["创建 knowledge_document<br/>+ document_file"]
    AJ --> AK["上传任务 status=CONVERTED"]
    AF -->|"取消"| AL["释放前端文件对象<br/>不做任何处理"]
    X -->|"取消"| AL
```

## 2. 整体状态流转图

```mermaid
graph TD
    subgraph "Stage1 任务创建"
        S1_A["文档上传至 MinIO"] --> S1_B["新增上传任务<br/>上传任务状态=PENDING(待申请上传链接)<br/>新增解析任务<br/>解析任务状态=PENDING(待申请上传链接)"]
        S1_B --> S1_C["发布 document.parse.pending"]
    end

    subgraph "Stage2 消费者：申请链接并上传文件"
        S2_A["消费 document.parse.pending"] --> S2_B{"申请上传链接"}
        S2_B --"申请失败"--> S2_C["上传任务状态=LINK_FAILED(申请上传链接失败)<br/>解析任务状态=LINK_FAILED(申请上传链接失败)"] --> S2_C1["定时任务处理申请上传链接失败的情况，重新申请上传链接"] --> S2_B
        S2_B --"申请成功"--> S2_D["解析任务状态=WAITING_UPLOAD(等待文件上传)<br/>上传任务状态=WAITING_UPLOAD(等待文件上传)<br/>分段解析状态=WAITING_UPLOAD(等待文件上传)"]
        S2_D --> S2_E["上传文件"] --> S2_E2{"上传结果"}
        S2_E2 --"全部上传成功"--> S2_G["所有分段解析状态=PARSING(解析中)<br/>上传任务状态=PARSING(解析中)<br/>解析任务状态=PARSING(解析中)"]
        S2_E2 --"部分上传成功"--> S2_F["上传失败的分段解析状态=UPLOAD_FAILED(文件上传失败)<br/>上传成功的分段解析状态=PARSING(解析中)<br/>上传任务状态保持PARSING(解析中)<br/>解析任务状态保持PARSING(解析中)"]
        S2_E2 --"全部上传失败"--> S2_F2["所有分段解析状态=UPLOAD_FAILED(文件上传失败)<br/>上传任务状态=UPLOADING(文件上传中)<br/>解析任务状态=UPLOADING(文件上传中)"]
        S2_F --"失败分段进入Stage2兜底重试"--> S2_H
        S2_F --"成功分段满足Stage3轮询条件"--> T_A
        S2_F2 --"失败分段进入Stage2兜底重试"--> S2_H
    end

    subgraph "Stage2 定时任务兜底：上传失败处理"
        S2_H["Stage2 定时任务兜底"] --> S2_H2["取出上传失败的分段任务"]
        S2_H2 --> S2_I{"是否超时？"}
        S2_I --"否"--> S2_E["上传文件（异步并发处理）"]
        S2_I --"是（失败分段均已超时）"--> S2_J["该分段任务状态=PARSE_FAILED(解析失败)"]
        S2_J --> S2_K{"该batch下是否都是失败分段？"}
        S2_K --"否"--> S2_M["不做处理，等待Stage3处理"]
        S2_K --"是"--> S2_L["解析任务状态=FAILED(存在失败情况)<br/>上传任务状态=USER_DECISION(待人工决策)"]
    end

    subgraph "Stage3 定时任务：获取 mineru 解析结果"
        T_A["Stage3 定时任务<br/>获取 mineru 解析结果"] --> T_E{"失败分段情况？"}
        T_E --"全部成功"--> T_C["解析任务状态=COMPLETED(解析完成)<br/>上传任务状态=COMPLETED(解析完成)"]
        T_E --"存在失败情况"--> T_D["失败分段状态=PARSE_FAILED(解析失败)<br/>成功分段状态=PARSED(解析成功)<br/>解析任务状态=FAILED(存在失败情况)<br/>上传任务状态=USER_DECISION(待人工决策)"]
    end

    subgraph "人工决策环节"
        M_A{"人工评判"} --"删除"--> M_B["上传任务/解析任务<br/>逻辑删除"]
        M_A --"重试"--> M_C["对失败分段任务发起新任务<br/>旧解析任务状态=COMPLETED(解析完成)<br/>新增解析任务<br/>解析任务状态=PENDING(待申请上传链接)<br/>上传任务状态=PENDING(待申请上传链接)"]
        M_C --> M_C1["旧失败分段状态=RETRIED(已重试)"]
        M_C1 --> M_E["发布 document.parse.pending"]
    end

    subgraph "Stage4 解析结果处理：md 合并与入库"
        S3_A["Stage4 mineru 解析结果处理(md文件合并等等)<br/>md文件合并处理上传minio<br/>记录 knowledge_document + document_file"] --> S3_J{处理是否成功?}
        S3_J --"成功"--> S3_B["上传任务状态=CONVERTED(md转换完成)"]
        S3_J --"失败（异常）"--> S3_C["上传任务状态=CONVERT_FAILED(md转换失败)"]
        S3_C --> S3_K["Stage4 定时任务兜底：重新执行 md 合并与入库<br/>不限制重试次数，用户可主动删除终止"]
        S3_K --> S3_A
    end

    S1_C --> S2_A
    S2_G --"满足Stage3轮询条件"--> T_A
    S2_L --> M_A
    T_D --> M_A
    T_C --> S3_A
    M_E --> S2_A
```

存在失败情况时，**解析任务统一为 `FAILED`**，**上传任务统一为 `USER_DECISION`**，进入人工决策（重试或删除）。

消息主题：`document.parse.pending`（Stage2）、`document.md.pending`（Stage4）。  
定时兜底：Stage2-A（`LINK_FAILED`/`PENDING`）、Stage2-B（`UPLOAD_FAILED`）、Stage3（轮询）、Stage4（`CONVERT_FAILED`/`COMPLETED`）。

```mermaid
graph LR
    A["PENDING(待申请上传链接)"] -->|"申请失败"| B["LINK_FAILED(申请上传链接失败)"]

    C -->|"全部上传成功"| E["PARSING(解析中)"]
    C -->|"部分上传成功"| E
    C -->|"全部上传失败"| D["UPLOADING(文件上传中)"]
    D -->|"兜底超时全部失败"| F["USER_DECISION(待人工决策)"]
    D -->|"兜底重试成功"| E
    E -->|"Stage3全部成功"| G["COMPLETED(解析完成)"]
```
