# 切分与向量化流程

资料上传 / 网页爬虫得到「已转换」文档后的共享写路径（`knowledge-content`）。产物写入片段表 + Milvus（默认灰度标签 `canary`），发布为正式版 `prod` 后供 [知识问答](./知识问答流程.md) 检索。

## 1. 提交创建任务

前端提交 Embedding 任务：落库为「待处理」，再投递消息。预览接口只切分展示，不落库、不入队。

```mermaid
sequenceDiagram
    autonumber
    participant FE as 前端
    participant API as Embedding 接口
    participant Svc as 任务服务
    participant DB as 数据库
    participant MQ as 消息流

    FE->>API: 创建 Embedding 任务
    API->>Svc: 校验文档并创建
    Svc->>DB: 任务状态 = 待处理
    Svc->>MQ: 投递「Embedding 待处理」消息（含任务 ID）
```

同文档若已有进行中任务（待处理 / 切分中 / 向量化中），不可再提交。

## 2. 文档切分

消费者领取后进入切分阶段：按文件读 Markdown → 按策略切分 → 写本任务片段（可清理同文档旧灰度数据，不动正式版）。

```mermaid
sequenceDiagram
    autonumber
    participant MQ as 消息流
    participant Consumer as Embedding 消费者
    participant Svc as 任务服务
    participant Split as 切分服务
    participant MinIO as 对象存储
    participant DB as 数据库

    MQ->>Consumer: Embedding 待处理消息
    Consumer->>Svc: 推进流水线
    Svc->>DB: 待处理 → 切分中
    Svc->>Split: 按文件逐个切分

    loop 每个尚未切分的文件
        Split->>MinIO: 读取 Markdown
        Split->>Split: 按策略切分
        Split->>DB: 写入本任务片段
    end

    alt 切分成功
        Split->>DB: 文档标记已切分 / 任务 → 向量化中
    else 切分失败
        Svc->>DB: 任务 → 切分失败
    end
```

切分支持按文件断点续跑：已落库的文件重试时会跳过。

## 3. 向量化写入

切分成功后进入向量化：先调 Embedding 接口写片段向量，再批量写入 Milvus（`release_tag=canary`）。

```mermaid
sequenceDiagram
    autonumber
    participant Svc as 任务服务
    participant Vec as 向量写入服务
    participant Pool as 并发工人池
    participant DB as 数据库
    participant Milvus as Milvus

    Note over Svc: 任务已处于「向量化中」
    Svc->>Vec: 分批向量化并入库

    Vec->>Pool: 阶段一：待嵌入片段 → 调用 Embedding
    Pool->>DB: 片段标记已嵌入（保留向量二进制）

    Vec->>Pool: 阶段二：已嵌入片段 → 写入向量库
    Pool->>DB: 片段标记已入向量库
    Pool->>Milvus: upsert（任务 ID + 灰度标签 canary）

    alt 全部成功
        Vec->>DB: 文档标记已入向量库 / 任务 → 已完成
    else 失败
        Svc->>DB: 任务 → 向量化失败<br/>已写入的片段保留，重试从剩余片段续跑
    end
```

## 4. 任务状态机

按阶段拆开：提交 → 切分 → 向量化；失败可就地重试，不退回「待处理」。

### 4.1 提交与领取

```mermaid
stateDiagram-v2
    [*] --> PENDING: 创建任务
    PENDING --> CHUNKING: 消费者领取
```

### 4.2 切分阶段

```mermaid
stateDiagram-v2
    [*] --> CHUNKING
    CHUNKING --> EMBEDDING: 切分成功
    CHUNKING --> CHUNK_FAILED: 切分失败
    CHUNK_FAILED --> CHUNKING: 重试（重置为切分中）
```

### 4.3 向量化阶段

```mermaid
stateDiagram-v2
    [*] --> EMBEDDING
    EMBEDDING --> COMPLETED: 向量写入成功（终态）
    EMBEDDING --> EMBED_FAILED: 向量化失败
    EMBED_FAILED --> EMBEDDING: 重试（保留切分结果，续跑剩余片段）
```

### 4.4 状态一览

| 状态 | 阶段 | 含义 |
|------|------|------|
| `PENDING` 待处理 | 提交 | 已创建，等待消费 |
| `CHUNKING` 切分中 | 切分 | 正在读文件并切分落库 |
| `CHUNK_FAILED` 切分失败 | 切分 | 可重试，重置为切分中 |
| `EMBEDDING` 向量化中 | 向量化 | 正在 Embedding 并写入 Milvus |
| `EMBED_FAILED` 向量化失败 | 向量化 | 可重试，保留已切分/已写入片段 |
| `COMPLETED` 已完成 | 向量化 | 终态成功 |

## 5. 在入库链路中的位置

