# 爬虫 Agent 用户需求场景讨论

> 基于聊天框交互视角，梳理用户可能的所有操作场景
> 讨论状态：初稿待完善

---

## 一、单任务生命周期核心操作

### 1. 发起爬取任务
- **用户表达**："帮我爬一下 xxx 网站"
- **输入**：目标 URL + 自然语言需求描述
- **说明**：Agent 分析站点后进入策略确认环节

### 2. 查询任务详情
- **用户表达**："那个任务怎么样了？""进度到哪了？"
- **核心信息**：当前状态、已爬取数量、错误数、耗时、已爬到的内容预览
- **说明**：支持跨会话查询（通过 task_id）

### 3. 修复失败任务
- **用户表达**："爬失败了，帮我看下原因修一下"
- **场景**：执行过程中部分页面或全部页面爬取失败
- **能力**：Agent 分析失败原因（反爬/超时/页面结构变化），调整参数后重试

### 4. 删除任务
- **用户表达**："把这个任务删了"
- **说明**：销毁任务及其关联数据

### 5. 放弃爬取，合并已爬结果
- **用户表达**："不爬了，先把爬到的合并了吧"
- **场景**：爬取过程中用户判断已爬数据够用，终止后续爬取直接进入下游处理

---

## 二、任务管理

### 7. 暂停/恢复任务
- **用户表达**："先停一下，晚上再继续"
- **场景**：任务过大占资源，或用户临时需要让出带宽

---

## 三、策略交互

### 8. 策略确认与参数调整
- **用户表达**："只爬最近三个月的文章""图片不要了，只要文字"
- **场景**：Agent 分析站点后生成爬取方案，用户觉得方案不合适，手动调整参数
- **时机**：Trial 阶段展示方案后，用户确认前

## 六、场景关联关系说明

- **修复失败与重试**：修复失败 = 诊断分析 + 参数调整 + **重试执行**，重试是修复失败的最后一步，不是独立场景。用户想直接重试相当于"跳过诊断，直接执行修复的最后一步"。
