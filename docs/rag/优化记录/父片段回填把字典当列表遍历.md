# 父片段回填把字典当列表遍历

2026-10-06。执行 8 四项分接近 0：召回率 0.023，精确度 0.022，忠实度 0.068，相关性 0.124。45 题里 44 题没有上下文。

## 现象

采数接口仍然返回 200。检索日志里 43 次是：

```text
AttributeError: 'str' object has no attribute 'chunk_id'
```

问答中间件把这个异常吃掉，改成无资料继续回答。模型凭通用知识作答，所以忠实度和相关性也低。

有父片段的命中会走到这里。没有父片段的那一次检索是成功的，返回了 5 条上下文。

## 原因

`DocumentSegmentRoDao.get_by_chunk_ids` 返回的是 `chunk_id → 片段` 字典。回填代码又对它做了一次遍历：

```python
parents = await DocumentSegmentRoDao.get_by_chunk_ids(parent_ids)
by_id = {h.chunk_id: h for h in parents}
```

字典直接迭代得到的是字符串 key。这行 `by_id` 后面也没有使用。异常发生在换父片段全文之前，命中列表被丢成空。

## 处理

删掉这次多余遍历，直接用返回的字典按父片段 ID 取全文。父片段正文为空时保留子片段原文。

文件：`knowledge-retrieval/src/knowledge_retrieval/service/document_vector_retrieve_service.py` 的 `_expand_parents`。
