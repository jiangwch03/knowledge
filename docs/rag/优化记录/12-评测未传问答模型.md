# 评测未传问答模型

2026-10-06。执行 4 采数失败。页面上看起来像日期序列化，库里的错误是 `runtime.context.model_id` 为空。

## 现象

评测请求没有带 `modelId`。检索中间件在进问答之前就拒绝了这次调用，要求上下文里必须有模型 ID。

单题直连、补上默认模型之后，同一道题可以返回。

## 原因

普通问答在模型 ID 为空时，会落到 `get_base_chat_model` 的默认适配。评测这条路径把 `model_id=None` 放进 `AgentIdentityContext`，中间件在那个兜底之前就停了。

测评集适配上的模型是打分用的裁判模型，不是回答模型。

## 处理

`eval_answer` 先调用 `resolve_qa_model_id`。请求没指定模型时，用知识问答适配里的第一个模型。指定了但不可用时同样回退，并打警告。

- `knowledge-retrieval/src/knowledge_retrieval/agents/utils/llm_util.py`
- `knowledge-retrieval/src/knowledge_retrieval/agents/service/knowledge_qa_agent_service.py`
