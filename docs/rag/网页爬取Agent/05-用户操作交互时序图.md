## 一、创建会话与发送消息

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant DB as 数据库

    U->>W: 点击「新建会话」
    W->>C: POST /api/rag/crawler/session
    C->>DB: INSERT web_crawler_session
    C-->>W: session_id
    W->>W: 选中新会话，显示欢迎语

    U->>W: 输入目标URL，点击发送
    W->>DB: INSERT web_crawler_message (role=user)
    W->>C: POST /api/rag/crawler/chat (SSE)
    C->>C: 构建 LangGraph State
    C-->>W: SSE 流式返回
    W-->>U: 实时展示 Agent 回复
    C->>DB: INSERT web_crawler_message (role=assistant)
```

## 二、Agent 分析与工具调用

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant T as 分析工具
    participant LLM as Qwen-Plus

    U->>W: 发送目标URL
    W->>C: POST /api/rag/crawler/chat (SSE)
    
    C->>LLM: 分析URL，决策调用工具
    LLM-->>C: 调用 fetch_robots_txt
    C->>T: fetch_robots_txt(url)
    T-->>C: 结构化结论 (≤200 tokens)
    C->>DB: INSERT tool消息
    C-->>W: SSE: 工具调用展示

    C->>LLM: 分析结果，决策下一步
    LLM-->>C: 调用 fetch_sitemap
    C->>T: fetch_sitemap(url)
    T-->>C: 结构化结论 (≤500 tokens)
    C->>DB: INSERT tool消息
    C-->>W: SSE: 工具调用展示

    C->>LLM: ReAct循环继续...
    Note over C,LLM: 最多3轮ReAct + 1次Reflection

    C->>LLM: 生成提问
    LLM-->>C: 业务语言提问
    C-->>W: SSE: Agent提问
    W-->>U: 展示提问
```

## 三、策略确认与任务提交

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant DB as 数据库

    Note over W: Agent生成策略配置摘要
    W->>W: 渲染策略确认卡片
    W-->>U: 展示配置摘要 + 操作按钮

    alt 用户确认配置
        U->>W: 点击「确认配置」
        W->>C: POST /api/rag/crawler/task
        C->>DB: INSERT crawl_task (status=PENDING)
        C->>DB: INSERT web_crawler_session_task
        C->>DB: INSERT web_crawler_message_task
        C->>C: 发布后台任务
        C-->>W: task_id
        W->>W: 展示任务进度卡片
    else 用户修改参数
        U->>W: 点击「修改参数」
        W->>W: 进入编辑模式
        U->>W: 修改参数值
        U->>W: 点击「更新方案」
        W->>W: 重新展示摘要
        Note over W: 可多轮迭代
    else 用户重新生成
        U->>W: 点击「重新生成」
        W->>C: POST /api/rag/crawler/chat (SSE)
        C->>C: Agent重新推理生成新方案
        C-->>W: SSE: 新的策略配置
        W->>W: 更新策略确认卡片
    end
```

## 四、任务执行与进度轮询

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant C4AI as crawl4ai
    participant DB as 数据库
    participant MinIO as MinIO

    W->>C: GET /api/rag/crawler/task/{task_id}
    C->>DB: 查询 crawl_task
    C-->>W: status=PENDING, progress=0

    Note over C: Worker 开始执行
    C->>DB: UPDATE status=RUNNING
    C->>C4AI: 执行整站爬取

    loop 轮询进度 (每3秒)
        W->>C: GET /api/rag/crawler/task/{task_id}
        C-->>W: status, progress, current_step
        W-->>U: 更新进度条
    end

    C4AI-->>C: 爬取完成
    C->>MinIO: 上传 Markdown 文件
    C->>DB: INSERT knowledge_document
    C->>DB: UPDATE status=COMPLETED → CONVERTED

    W->>C: GET /api/rag/crawler/task/{task_id}
    C-->>W: status=CONVERTED, progress=100
    W-->>U: 展示完成统计 + 文档列表
```

## 五、任务失败与 USER_DECISION

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant C4AI as crawl4ai
    participant LLM as Qwen-Plus
    participant DB as 数据库

    C->>C4AI: 执行爬取
    C4AI-->>C: 爬取失败

    Note over C: 第一层：规则自动重试 (最多3次)
    C->>C4AI: 调整参数重试
    C4AI-->>C: 仍然失败

    Note over C: 第二层：静默调LLM分析
    C->>LLM: 失败上下文 (≤1200 tokens)
    LLM-->>C: 参数调整建议
    C->>C4AI: 合并补丁重试
    C4AI-->>C: 仍然失败

    Note over C: 第三层：参数归属判断
    alt 用户参数问题
        C->>DB: UPDATE status=USER_DECISION
        C-->>W: 消息流通知
        W->>DB: INSERT system消息
        W-->>U: 展示待决策任务

        alt 用户调整参数重试
            U->>W: 点击「调整参数重试」
            W->>W: 展示编辑模式
            U->>W: 修改参数
            W->>C: POST /api/rag/crawler/task (重试)
            C->>DB: UPDATE status=PENDING
        else 用户放弃
            U->>W: 点击「放弃删除」
            W-->>U: 二次确认弹窗
            U->>W: 确认删除
            W->>C: DELETE task
            C->>DB: 逻辑删除任务
        end
    else Agent/默认参数问题
        C->>DB: UPDATE status=FAILED
    end
```

## 六、文档预览与下载

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant MinIO as MinIO

    U->>W: 点击「查看文档」
    W->>C: GET /api/rag/crawler/document/list
    C-->>W: 文档列表
    W-->>U: 展示文档列表卡片

    alt 预览文档
        U->>W: 点击「预览」
        W->>C: 获取文档内容
        C->>MinIO: 下载 Markdown
        MinIO-->>C: 文件内容
        C-->>W: Markdown 内容
        W->>W: 渲染全屏 Modal
        W-->>U: 展示 Markdown 预览
    else 下载文档
        U->>W: 点击「下载」
        W->>C: 获取下载链接
        C->>MinIO: 生成预签名URL
        MinIO-->>C: 下载URL
        C-->>W: 下载链接
        W-->>U: 触发浏览器下载
    end
```

## 七、会话切换

```mermaid
sequenceDiagram
    actor U as 用户
    participant W as knowledge-web
    participant C as knowledge-content
    participant DB as 数据库

    U->>W: 点击另一个会话
    W->>W: 清空当前聊天区
    
    alt 有未保存输入
        W-->>U: 提示「当前输入未保存，是否切换？」
        U->>W: 确认切换
    end

    W->>C: GET /api/rag/crawler/session/{id}/messages
    C->>DB: 查询消息历史
    C-->>W: 消息列表
    W->>W: 渲染消息历史
    W-->>U: 展示目标会话内容

    Note over W: 后台任务不受影响，轮询继续
```
