## 一、新会话策略生成并提交爬取

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as 前端
    participant Chat as /crawler/chat
    participant Svc as CrawlerAgentService
    participant Sup as Supervisor
    participant Plan as Planning
    participant MQ as MQ/Worker

    U->>FE: 新建会话 / 输入 URL
    FE->>Chat: POST /session (创建)
    FE->>Chat: POST /{sid}/message (SSE)
    Chat->>Svc: stream_chat
    Svc->>Sup: astream
    Sup->>Plan: task(planning_agent)
    Plan->>Plan: 探站工具 + trial_crawl
    Plan-->>Sup: crawl_config 回流
    Sup-->>FE: token / tool_call / message
    U->>FE: 「确认爬取」
    FE->>Chat: POST /{sid}/message
    Sup->>Sup: crawl_execute tool_call
    Sup-->>FE: user_choice (strategy_confirmation)
    U->>FE: approve
    FE->>Chat: POST /{sid}/resume
    Sup->>MQ: 创建 PENDING + 投递
    Sup-->>FE: 成功 message + done
    MQ-->>FE: 任务 Tab 轮询可见进度
```

## 二、HITL 拒绝

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as 前端
    participant Chat as Chat API
    participant Sup as Supervisor

    Sup-->>FE: user_choice
    U->>FE: reject
    FE->>Chat: POST /resume {reject}
    Chat->>Sup: Command(resume=reject)
    Sup-->>FE: 工具未执行，继续对话引导
```

## 三、任务暂停与恢复（REST）

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as 任务 Tab
    participant API as /crawler/task
    participant Exec as Executor

    U->>FE: 暂停
    FE->>API: POST /{task_id}/pause
    API->>Exec: Redis 暂停标记
    Exec-->>API: 当前页结束后 PAUSED
    U->>FE: 恢复
    FE->>API: POST /{task_id}/resume
    API-->>FE: PENDING 并重新入队
```

对话路径等价调用 `pause_crawl_task` / `resume_crawl_task`（多一步 HITL）。

## 四、USER_DECISION 修复重试

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as 前端
    participant Sup as Supervisor
    participant Plan as Planning

    Note over FE: 任务状态 USER_DECISION
    U->>FE: 「按建议改参数重试」
    FE->>Sup: SSE message
    Sup->>Sup: query_crawl_task
    Sup->>Plan: 针对 failed_urls 调参+trial
    Plan-->>Sup: 新 crawl_config
    Sup->>Sup: crawl_retry (HITL)
    U->>FE: approve
    Sup-->>FE: 任务重新 PENDING
```

```mermaid
sequenceDiagram

    participant Sup as Supervisor
    participant Plan as Planning
```
