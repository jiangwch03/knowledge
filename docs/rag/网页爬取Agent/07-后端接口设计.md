## 一、接口汇总

接口统一前缀：`/api/rag`

| 序号 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 1 | `/api/rag/crawler/session` | POST | 创建会话 |
| 2 | `/api/rag/crawler/session/list` | GET | 会话列表 |
| 3 | `/api/rag/crawler/session/{session_id}` | PUT | 重命名会话 |
| 4 | `/api/rag/crawler/session/{session_id}` | DELETE | 删除会话 |
| 5 | `/api/rag/crawler/session/{session_id}/messages` | GET | 获取历史消息 |
| 6 | `/api/rag/crawler/chat` | POST | Agent 对话（SSE） |
| 7 | `/api/rag/crawler/task` | POST | 提交爬取任务 |
| 8 | `/api/rag/crawler/task/{task_id}` | GET | 查询爬取任务 |
| 9 | `/api/rag/crawler/task/{task_id}/failed-urls` | GET | 失败 URL 列表 |
| 10 | `/api/rag/crawler/document/list` | GET | 爬取结果文档列表 |

## 二、接口详细设计

### 2.1 创建会话

`POST /api/rag/crawler/session`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_title` | string | 是 | 会话标题 |
| `model_id` | long | 否 | 模型 ID，关联 `ai_models` 表 |

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": "session_abc123"
}
```

### 2.2 会话列表

`GET /api/rag/crawler/session/list`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `page_num` | int | 是 | 页码，默认 1 |
| `page_size` | int | 是 | 每页条数，默认 20 |
| `session_title` | string | 否 | 搜索关键词，模糊匹配 |

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "total": 10,
    "rows": [
      {
        "session_id": "session_abc123",
        "session_title": "爬取FastAPI文档",
        "model_id": 1,
        "status": "ACTIVE",
        "create_time": "2026-06-20 10:00:00"
      }
    ]
  }
}
```

### 2.3 重命名会话

`PUT /api/rag/crawler/session/{session_id}`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | 路径参数 |
| `session_title` | string | 是 | 新标题 |

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

### 2.4 删除会话

`DELETE /api/rag/crawler/session/{session_id}`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | 路径参数，级联软删除消息 |

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功"
}
```

### 2.6 Agent 对话（SSE）

`POST /api/rag/crawler/chat`

**Content-Type：** `text/event-stream`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | 会话 ID |
| `content` | string | 是 | 用户消息内容 |

**SSE 事件格式：**

```
data: {"type": "token", "content": "好的"}
data: {"type": "token", "content": "，我来"}
data: {"type": "tool_call", "tool_name": "fetch_robots_txt", "tool_input": {"url": "..."}}
data: {"type": "tool_result", "tool_name": "fetch_robots_txt", "result": {...}}
data: {"type": "done", "message_id": 5}
```

### 2.7 提交爬取任务

`POST /api/rag/crawler/task`

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `session_id` | string | 是 | 会话 ID |
| `message_id` | long | 是 | 触发任务的消息 ID |
| `target_url` | string | 是 | 目标 URL |
| `crawl_config` | object | 是 | crawl4ai 配置 JSON |

**响应：**

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": "crawl_uuid456"
}
```
