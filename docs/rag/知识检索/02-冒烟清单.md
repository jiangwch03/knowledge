# 知识检索服务手动冒烟清单

服务：`scripts/start-retrieval.sh`（端口 9101）  
种子：`sql/upgrade_knowledge_retrieval.sql`  
Milvus：`sql/milvus/manage_document_vector.py` + `MIGRATION_ACL_BM25.md`

## 前置

1. MySQL 执行升级 SQL；参数设置中填写真实 `rag.tavily.api_key`（可选）
2. 重建/重嵌向量（含 dept_id/user_id）
3. 配置 `knowledge_qa_agent` 模型适配（可临时复用 crawler 适配）
4. 启动 admin / content / retrieval / web

## 用例

1. **混合检索**
   - `POST /retrieval/search`，query 非空，默认 releaseTag=prod
   - 空 query 应校验失败
   - 无命中返回空 hits（非 5xx）
2. **多轮知识问答**
   - 前端「知识问答」新建会话 → 问 Milvus/LangGraph 相关问题
   - SSE 出现 `citations` + token 流
3. **主题未命中客服路径**
   - 问「今天中午吃什么」
   - 无知识库 citations，不伪造引用；回答走客服式路径
4. **Tavily 降级**
   - Key 为空时会话仍可回答；工具返回友好失败
5. **守卫**
   - admin `/ai/chat` 仍不走知识库检索
   - retrieval 进程无 embedding consumer
