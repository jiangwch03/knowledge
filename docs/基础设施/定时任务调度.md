# 定时任务调度与同步

> 模块位置：`knowledge-common/src/knowledge_common/config/get_scheduler.py`

## 1. 概述

基于 APScheduler + Redis 分布式锁实现定时任务调度，支持多服务（admin / content / retrieval）独立运行、`app_scope` 隔离、Leader 选举、双同步机制（定时轮询 + 广播即时通知）。

---

## 2. Leader 选举与启动流程

```mermaid
graph TD
    Start["SchedulerUtil.init_system_scheduler(redis, app_scope)"] --> TryLock["尝试获取 Application 锁<br/>SET lock_key worker_id NX EX 30"]
    TryLock --> Check{"抢到锁?"}
    Check -->|是| Leader["成为 Leader"]
    Check -->|否| Worker["成为普通 Worker<br/>不启动调度器"]
    Leader --> Config["_configure_scheduler()<br/>懒加载 jobstore"]
    Config --> StartScheduler["scheduler.start()"]
    StartScheduler --> LoadJobs["从数据库加载任务<br/>JobDao.get_job_list_for_scheduler(app_scope)"]
    LoadJobs --> Register["逐个注册到调度器<br/>_add_job_to_scheduler(item)"]
    Register --> AddListener["添加事件监听器"]
    AddListener --> AddSync["添加定时同步任务<br/>每 10 秒同步一次"]
    AddSync --> Done["启动完成"]
```

**关键设计**：
- 数据库是任务状态的**唯一真相源**
- Leader 启动只是将数据库中已启用任务镜像到内存调度器
- Leader 挂了，其他 Worker 抢到锁后重新加载，数据不丢失

## 3. app_scope 任务隔离

```mermaid
graph LR
    DB[(sys_job 表<br/>app_scope 字段)] --> Admin["knowledge-admin<br/>app_scope = knowledge-admin"]
    DB --> Content["knowledge-content<br/>app_scope = knowledge-content"]
    DB --> Retrieval["knowledge-retrieval<br/>app_scope = knowledge-retrieval"]
    Admin -->|"只加载"| AdminJobs["admin 专属任务"]
    Content -->|"只加载"| ContentJobs["content 专属任务"]
    Retrieval -->|"只加载"| RetrievalJobs["retrieval 专属任务"]
```

- `sys_job` 表通过 `app_scope` 字段标识任务所属应用
- 各服务启动时只加载 `app_scope = 自身 APP_NAME` 的任务
- 避免跨服务加载任务导致 `ModuleNotFoundError`

## 4. 双同步机制

### 4.1 定时轮询（兜底）

```mermaid
graph LR
    Scheduler["APScheduler"] -->|"每 10 秒"| SyncJob["_scheduler_job_sync"]
    SyncJob --> Compare["对比数据库 update_time<br/>与本地缓存"]
    Compare -->|有变更| Reload["重新加载任务"]
    Compare -->|无变更| Skip["跳过"]
```

### 4.2 广播即时通知（实时）

```mermaid
sequenceDiagram
    participant Admin as knowledge-admin<br/>(任务管理入口)
    participant Redis as Redis Pub/Sub
    participant TargetLeader as 目标服务 Leader<br/>content / retrieval 等
    participant Scheduler as APScheduler

    Admin->>Admin: 管理员新增/修改/删除任务
    Admin->>Redis: PUBLISH scheduler:global:sync<br/>{app_scope: knowledge-content, action: sync}
    Redis->>TargetLeader: 消息推送
    TargetLeader->>TargetLeader: on_global_sync_message(msg)
    TargetLeader->>TargetLeader: 检查: 是否 Leader?
    TargetLeader->>TargetLeader: 检查: app_scope 匹配?
    TargetLeader->>Scheduler: request_scheduler_sync()
    Scheduler->>Scheduler: 从数据库重新加载任务
```

**订阅者位置**：`knowledge_common/message/subscriber/scheduler_subscriber.py`

### 4.3 execute_once 即时执行

```mermaid
sequenceDiagram
    participant Admin as knowledge-admin
    participant Redis as Redis Pub/Sub
    participant TargetLeader as 目标服务 Leader

    Admin->>Redis: PUBLISH scheduler:global:sync<br/>{action: execute_once, job_id: 123}
    Redis->>TargetLeader: 消息推送
    TargetLeader->>TargetLeader: _execute_job_once_from_broadcast(job_id)
    TargetLeader->>TargetLeader: 立即执行指定任务
```

## 5. 广播通知触发时机

admin 后台在以下操作后发送广播：

| 操作 | 广播内容 |
|------|---------|
| 新增任务 | `{action: sync, app_scope: xxx}` |
| 修改任务 | `{action: sync, app_scope: xxx}` |
| 删除任务 | `{action: sync, app_scope: xxx}` |
| 修改任务状态 | `{action: sync, app_scope: xxx}` |
| 立即执行 | `{action: execute_once, job_id: xxx}` |

## 6. 锁丢失处理

```mermaid
graph TD
    Renewal["锁续期任务<br/>每 10s EXPIRE"] --> Check{"锁还存在?"}
    Check -->|是| Continue["继续续期"]
    Check -->|否| Lost["on_lock_lost()"]
    Lost --> SetFalse["_is_leader = False"]
    SetFalse --> CancelSync["取消同步任务"]
    CancelSync --> Shutdown["scheduler.shutdown()"]
    Shutdown --> Dispose["释放数据库引擎"]
    Dispose --> Reacquire["启动重竞选任务<br/>每 5s 尝试"]
```

## 7. MyCronTrigger 扩展

继承 APScheduler `CronTrigger`，支持 6/7 位 cron 表达式（含秒）：

| 字段位置 | 含义 | 特殊值 |
|---------|------|--------|
| 第 1 位 | 秒 | - |
| 第 2 位 | 分 | - |
| 第 3 位 | 时 | - |
| 第 4 位 | 日 | `?` `L` `W` |
| 第 5 位 | 月 | - |
| 第 6 位 | 星期 | `?` `L` `#` |
| 第 7 位（可选） | 年 | - |

**特殊符号**：
- `?`：不指定（日/星期互斥）
- `L`：最后一个（如 `L` 在星期位表示最后一个星期六）
- `W`：最近工作日（如 `15W` 表示 15 号最近的工作日）
- `#`：第几个星期几（如 `5#2` 表示第二个星期四）

## 8. JobStore 配置

```python
job_stores = {
    'default': MemoryJobStore(),
    'sqlalchemy': SQLAlchemyJobStore(url=SYNC_SQLALCHEMY_DATABASE_URL),
    'redis': RedisJobStore(**redis_config),
}
```

- `default`：内存存储（实际使用的 jobstore）
- `sqlalchemy`：数据库持久化（APScheduler 内部元数据）
- `redis`：Redis 存储（备用）
